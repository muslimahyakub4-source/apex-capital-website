# Apex Capital Financial Services Website

## Project Overview

This project is a corporate organization website developed using HTML, CSS, and JavaScript. The website represents Apex Capital Financial Services and provides information about the company's services, team, projects, career opportunities, and contact details.

## Features

- Responsive design for mobile, tablet, and desktop devices
- Modern and user-friendly interface
- Navigation menu
- Services page
- Portfolio/Projects page
- Team/Management page
- Blog/News section
- Careers page
- Contact form
- FAQ section
- Testimonials page
- Privacy Policy page
- Terms and Conditions page

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Pages Included

1. Home
2. About Us
3. Services
4. Projects / Portfolio
5. Team / Management
6. News / Blog
7. Careers
8. Contact Us
9. FAQs
10. Testimonials
11. Privacy Policy
12. Terms and Conditions

## How to Run the Project

1. Download or clone the project files.
2. Open the project folder.
3. Double-click the `index.html` file or open it with a web browser.
4. Navigate through the website using the menu.

## Deployment

The project can be deployed using GitHub Pages or Netlify.
